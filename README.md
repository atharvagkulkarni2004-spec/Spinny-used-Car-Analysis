# 🚗 Spinny Used Car Market Analysis Dashboard

## 📌 Project Overview
An interactive Power BI dashboard designed to analyze pricing trends and inventory insights for the Spinny used car market. This project leverages advanced DAX measures and SQL to extract actionable market intelligence, track vehicle availability, and optimize dynamic pricing strategies.

## 🛠️ Tech Stack
* **Data Visualization & Modeling:** Power BI, DAX
* **Database & Querying:** SQL
* **Tools & Environment:** VS Code, Git

## 📊 Key Features & Insights
* **Pricing Trends Analysis:** Tracked dynamic pricing variations across different vehicle segments, makes, and models.
* **Inventory Optimization:** Developed custom DAX measures to analyze inventory turnover and stock availability in real-time.
* **Interactive Dashboards:** Implemented user-friendly slicers and cross-filtering for deep-dive analysis by location, car brand, transmission type, and manufacturing year.
